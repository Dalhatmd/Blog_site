# Blog_site

Final project at ALX

## Description
This project is a blogging platform built using a combination of Python, HTML, CSS, and JavaScript. It serves as the final project for the ALX program, demonstrating the skills and knowledge acquired during the course.

## Features
- Create and manage blog posts
- User authentication and authorization
- Responsive design
- Commenting system

## Installation
To set up the project locally, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/Dalhatmd/Blog_site.git
    ```
2. Navigate to the project directory:
    ```sh
    cd Blog_site
    ```
3. Install the required dependencies:
    ```sh
    pip install -r requirements.txt
    ```
4. Set environment variables in a .env file
   ```sh
    required envs
   MYSQL_HOST
   MYSQL_PWD
   MYSQL_DB=Blog
   MYSQL_USER
   JWT_SECRET
5. Run the application:
    ```sh
    python api.v1.app.py
    ```

## Usage
- Access the application in your web browser at `http://localhost:8000`
- Register for an account or log in if you already have one
- Create, edit, and delete blog posts
- Comment on posts and engage with other users
